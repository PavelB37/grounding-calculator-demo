# Калькулятор вертикального заземлителя

Демонстрационная веб-версия калькулятора для расчета сопротивления вертикального заземлителя.

## Открыть калькулятор

После публикации через GitHub Pages калькулятор доступен по ссылке в разделе:

Settings → Pages

## Технологии

- HTML
- CSS
- JavaScript
- GitHub Pages
- В перспективе: Cloudflare Worker API

## Статус проекта

Демонстрационная версия. Расчетная методика будет переноситься в API поэтапно.
